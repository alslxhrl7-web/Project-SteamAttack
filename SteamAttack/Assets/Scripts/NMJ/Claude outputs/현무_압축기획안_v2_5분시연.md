## 1. 길 — Main 맵 위의 동선

Main 맵에 이미 있는 배치(좌표는 씬 기준)를 그대로 쓰고, 남쪽에서 북쪽으로 **한 방향으로만** 올라간다.

```
 북 ↑
 [건청궁 (0, 137)] ······ 오프닝 컷씬만 (플레이하지 않음)
        :
 [향원정 (0, 104)] ─ 안개문 → 보스 아레나 씬 로드      ④
        │
 [근정전 마당 (0, 35~56)] ─ 얼어붙은 품계석 사이, 잡몹 소규모   ③-2
        │
 [광화문 (0, -40)] ─ 문을 지나 궁 안으로
 [해태 앞 (0, -58)] ─ 중간보스 백동수                          ③
        │
 [육조거리 (0, -60 ~ -111)] ─ 관아 사이 큰길, 잡몹 + 첫 패링     ②
 [시작 (0, -111)] ─ 버려진 수레 옆
 남 ↓
```

| 구간 | Main 맵의 실제 위치 | 길이 | 활용하는 기존 오브젝트 |
|---|---|---|---|
| ① 오프닝 | 건청궁 (0, 137), 시점 표식 `시점_어명의 순간` | 컷씬 | 조선 최초의 전등, 물불 발전기, `어명의 순간` 인물 |
| ② 육조거리 | z −111 → −60, 폭 약 40m | 약 50m | 6조 관아, 버려진 수레, 괘서, 얼어붙은 백성 |
| ③ 광화문 앞 | 해태 사이 (0, −58), 시점 `시점_광화문과 백동수` | 반경 15m | 광화문, 해태 2기, `백검 백동수` 인물 배치 |
| ③-2 궁 안 | 광화문 (0, −40) → 근정전 마당 → 향원정 | 약 140m | 어도(御道), 근정전, 품계석, 동·서행각 |
| ④ 향원정 | 연못 앞 (0, 약 85) | — | 향원정, 연못 물안개 → **안개문 트리거** |

- **뒤로 못 가게:** 시작 지점 남쪽은 쓰러진 수레와 얼음벽으로 막고, 백동수를 쓰러뜨리기 전까지 광화문은 얼음으로 닫아 둔다. 백동수를 이기면 얼음이 깨지며 문이 열린다.
- **운종가·삼청동 기기창·흑수회 제단**은 이번 시연에서는 배경으로만 둔다(길에서 멀리 보이게).
- **보이지 않는 벽:** 육조거리 관아 사이, 궁 안 행각 바깥을 투명 콜라이더로 막아 길에서 벗어나지 않게 한다.
- 이동 거리는 시작부터 안개문까지 약 250m다. 달리면 40초 안쪽이라 시연 시간 대부분이 전투에 쓰인다.

## 3. 시스템 (v1에서 줄인 최소 세트)

### 3-1. 조작

| 키 | 동작 |
|---|---|
| WASD / SHIFT | 이동 / 전력질주 |
| SPACE | 구르기 (0.9초, 무적 0.5초) |
| 좌클릭 / 우클릭 | 환도: 약공격 / 강공격 · 화승총: 발사 / 조준(홀드) |
| TAB | 환도 ↔ 화승총 |
| C | 발도·납도 |
| CTRL | 패링(빨리뽑기) |
| Z | 증기발도 (증기 100) |
| Q | 시간 역행 |
| E | 회복약 (2개, 보충 없음) |
| T / 휠클릭 | 락온 |

### 3-2. 핵심 수치

| 시스템 | 값 |
|---|---|
| 플레이어 | 체력 100, 공격력 10, 강공격 ×2, 화승총 = 강공격(히트스캔 25m) |
| 패링 | CTRL, 동심원 겹침 ±0.15초(**시연 ±0.2초**), 증기 −10, 성공 시 증기 +20 · 약점 노출 3초(다음 1회 ×3), 쿨 2초 |
| 증기 | 최대 100. 약 +5, 강 +10, 패링 성공 +20 / 패링 −10, 화승총 −10, 시간 역행 −70, 증기발도 −100. 100이면 등에서 붉은 증기 |
| 증기발도 | Z, 증기 100 전량. 전방 4.5m·180°, 약공격 ×6. **현무 가갑을 부수는 유일한 수단** |
| 시간 역행 | Q, 5초 전으로, 증기 −70. 위치·방향·체력만 되돌리고 **증기는 되돌리지 않음**. 연출 0.8초 동안 무적 |
| 회복약 | 2개, 최대 체력 50%. 시연 동안 보충 없음 |

### 3-3. 삭제한 것

- **강화:** 특별한 석탄, 강화 단계, 장승 강화 UI 모두 삭제. 수치는 처음부터 끝까지 고정.
- **체크포인트(석탄대장군·증기여장군):** 오브젝트, 휴식, 몬스터 부활 모두 삭제.
- **석탄 두더지:** 땅굴 이동, 석탄통 기믹 삭제.
- 수류탄, 인벤토리 UI, 사망 화면 팁.

### 3-4. 체크포인트 없이 죽으면

5분 시연이라 죽어도 흐름이 끊기지 않게, 장승 대신 아래처럼 처리한다.

| 상황 | 처리 |
|---|---|
| 길(②, ③-2)에서 사망 | 0.5초 먹물 전환 후 **그 자리에서** 체력 50%로 일어남. 적은 그대로 |
| 백동수·현무전에서 사망 | 먹물 전환 후 **보스전 시작 상태**로 다시. 체력 100, 증기 0 |
| 같은 보스에게 2번 사망 | 보스 체력 30% 깎고 시작 (시연 완주용) |

- 저장 지점 오브젝트는 없다. 보스 입장 순간의 상태만 코드에서 기억한다.

## 4. 적과 보스

### 4-1. 길 위의 적 (2종)

| 적 | 체력 | 공격 | 패링 가능한 강공격 | 배치 |
|---|---|---|---|---|
| 근접 — 변이 포졸 | 50 | 창 찌르기 10 | **내려치기 15** (동심원) | 육조거리 3, 궁 안 2(선택) |
| 원거리 — 흑수회 궁수 | 40 | 화살 8, 2.5초 간격 | 없음 | 육조거리 1 (관아 지붕 위) |

- AI는 `NGH_EnemyAI`를 쓰고, 패링 훅(동심원 예고, 자세 붕괴, 약점 노출)만 추가 요청한다.
- Main 맵의 `13_인물 / 변이병`, `흑수회 광신도` 배치 위치를 스폰 위치 후보로 쓴다.

### 4-2. 중간보스 — 백동수 (광화문 앞, 1분)

5분 안에 들어가도록 v1보다 짧게 만든다.

| 항목 | 값 |
|---|---|
| 체력 | **200** (v1 300) |
| 서리 갑옷 | 평소 받는 피해 ×0.3, 약점 노출 중 ×1.0 |
| 목표 | 패링 3~4번이면 끝나는 결투 |

| 패턴 | 예고 | 피해 | 패링 |
|---|---|---|---|
| 초고속 발도 | 칼집에 손 + 동심원 0.6초 | 20 | **가능** |
| 서리 검기 | 바닥에 백색 선 0.7초 | 15 | 불가 (구르기) |

- 패턴 순서 고정: `[발도, 발도, 검기]` 반복. 짧은 되감기, 삼연 베기는 풀 버전으로 미룬다.
- 처치 시 대사 1줄 → 광화문 얼음이 깨지며 길이 열린다.

### 4-3. 최종보스 — 현무 (보스 아레나 씬, 2분)

| 페이즈 | 목표 | 패턴 |
|---|---|---|
| **1 흑철의 가갑** | 가갑 **2장** 파괴 (v1 4장) | 흑철 찍기(동심원, **패링 가능**, 25) · 꼬리 휩쓸기(적색 고리, 구르기, 20) |
| 전환 | 2초 | 뱀의 목이 솟음 |
| **2 쌍두의 폭주** | 체력 **300** (v1 600) | 뱀의 목 찌르기(잔상 + 동심원, **패링 가능**, 22) · 냉기 브레스(청색 부채꼴, 구르기) · **합동기 1회**(4초 충전, 체력 90%, 1 미만 불가 → **Q로 넘기기**) |
| 마무리 | 신핵 QTE | F → Z → 좌클릭 → Q (단계당 2초) |

- 가갑은 증기발도로만 부서진다. 찍기 패링 → 증기 +20 → 100 → Z.
- 합동기 직전 증기가 70 미만이면 바닥에 증기 구슬을 떨어뜨려 채워 준다.
- 시간 역류(가갑 복원) 패턴은 5분 안에 들어가지 않아 뺀다.

## 7. 완료 체크리스트

1. 육조거리 시작부터 엔딩까지 씬 전환 1번(안개문)으로 이어진다.
2. 시연자가 5분 ± 30초 안에 3회 연속 끝낸다.
3. 육조거리에서 패링을 반드시 한 번 본다.
4. 백동수는 패링 3~4번이면 끝나고, 패링 없이 때리면 확실히 느리다.
5. 현무 가갑은 증기발도로만 부서진다.
6. 합동기를 시간 역행으로 넘길 수 있고, 증기가 모자라면 보충된다.
7. 사망해도 흐름이 끊기지 않는다 (길: 제자리, 보스: 보스전 처음).
8. 길에서 벗어나거나 되돌아갈 수 없다.
9. 시연자 키 4개가 모두 작동한다.
