## 0. 한 줄 요약

> **어명을 받은 무사가 건청궁에서 출발해 한 갈래 길을 따라 궐 밖으로 나가 백동수를 꺾고, 다시 궁으로 돌아와 향원정에서 현무를 잡는다.**
> 갈림길과 파밍 없이, 길 위에서 만나는 적과 기믹이 곧 튜토리얼이 되는 10분짜리 일직선 구조다.

### 0-1. 무엇을 줄였나

| 원래 구상 | 압축안 | 이유 |
|---|---|---|
| 1시간 풀 버전, Act 3개 | 10분 일직선 루트 6구역 | 3주 안에 끝까지 이어지는 빌드가 우선 |
| 스테이지 여러 개 + 보스 맵 따로 | 맵 1장(루트) + 보스 아레나 1장 | 씬 전환 2번(시작, 아레나 진입)만 |
| 근접·원거리·크리처 + 흑수회 | 근접 1, 원거리 1, 석탄 두더지 1 | 10/7 회의 결정 그대로 |
| 화승총 + 수류탄 선택 | **화승총만** | 장승 선택 UI, 투척 궤적 제외 |
| 강화 3단계 + 인벤토리 | **강화 1회**(백동수 처치 보상) + 회복약 | 강화 체감은 한 번이면 충분 |
| 과열 모드 + 고압 참격 + 증기발도 | **증기발도 하나로 합침** | 아래 2-4 참고 |
| 민심 NPC, 탈것, 높이 기믹 | 배경 연출로만 | 플레이 범위 밖 |

## 1. 루트 맵 — 주인공이 따라가는 길

### 1-1. 동선

```
[Z0 건청궁 지하 기관실] ─ 어명·장비
        │  (궐 안 회랑)
[Z1 궐문 밖 운종가] ─ 근접 잡몹·원거리 잡몹, 첫 패링 ── 장승 ①
        │
[Z2 석탄 하역장] ─ 석탄 두더지, 석탄통 폭발로 길 뚫기, 첫 시간 역행
        │
[Z3 광화문 앞 광장] ─ 중간보스 백동수 (보스룸)
        │  (광화문을 지나 다시 궁 안으로)
[Z4 향원정 다리 앞] ─ 장승 ② (보스룸 직전 필수) · 안개문
        │
[Z5 얼어붙은 향원정 연못] ─ 최종보스 현무 (NMJ 보스 아레나)
```

- **궐 밖으로 나갔다가 궐 안으로 돌아오는 고리 모양 한 길**이다(통합 기획서 9.7 "궁궐 밖 중간보스 → 궁궐로 돌아와 최종보스"를 그대로 따름).
- 되돌아가는 길은 무너진 담, 얼어붙은 문, 높이차로 막는다. 플레이어는 앞으로만 간다.
- 길 양옆은 멈춘 눈송이, 불탄 초가, 괘서, 기도하는 백성 같은 **민심 연출**로 채운다(전투 없음).

### 1-2. 구역별 설계

| 구역 | 길이·형태 | 만나는 것 | 배우는 것 | 시연 시간 |
|---|---|---|---|---|
| **Z0 건청궁 기관실** | 실내 20m | 고종의 어명(컷신 20초), 장비 착용 | 이동, 카메라, 발도·납도(C) | 0:00~1:00 |
| **Z1 운종가** | 거리 60m, 폭 10m | 근접 잡몹 2 → 원거리 잡몹 1 → 근접 1(패링 강공격) | 약·강공격, 회피, **첫 패링(동심원)**, 화승총 조준 | 1:00~2:30 |
| **장승 ①** | 운종가 끝 | 석탄대장군·증기여장군 | 체크포인트, 휴식, 회복약 보충 | — |
| **Z2 석탄 하역장** | 흙바닥 마당 30×30m | 석탄 두더지 1, 무너진 석탄 더미가 길을 막음 | 석탄통 사격(한 방 처치), **첫 시간 역행** | 2:30~4:00 |
| **Z3 광화문 앞** | 원형 광장 반경 15m | **백동수** | 패링 → 약점 노출 → 3배 피해 | 4:00~6:00 |
| **Z4 향원정 다리** | 다리 25m | 장승 ②, 안개문 | 강화 1회(백동수 석탄), 저장 | 6:00~6:30 |
| **Z5 향원정 연못** | 아레나 (반경 25m, 평평한 얼음 16m) | **현무** 1·2페이즈, 신핵 QTE, 해빙 엔딩 | 지금까지 배운 것 전부 | 6:30~10:00 |

### 1-3. 구역 안에서 꼭 일어나야 하는 일 (스크립트 이벤트)

| 구역 | 이벤트 | 왜 필요한가 |
|---|---|---|
| Z1 | 패링 가능한 강공격을 쓰는 근접 잡몹이 길 한가운데 혼자 서 있다. 처음 패링 동심원이 뜰 때 시간 0.3배 + "CTRL" 안내 1회 | 패링을 반드시 한 번 보게 만든다 |
| Z2 | 입구에서 두더지가 석탄 더미 옆 석탄통을 건드려 **먼저 한 번 터지는 장면**을 보여준다 | 석탄통이 위험하다는 것을 미리 인식시킨다(통합 기획서 9.3 메모) |
| Z2 | 길을 막은 석탄 더미를 터뜨리면 증기관이 터져 플레이어가 크게 맞는다. "Q — 3초 전으로" 안내 | 시간 역행을 실수 복구 수단으로 처음 쓰게 한다 |
| Z3 | 입장 시 백동수와 짧은 대화 컷신(10초) | 옛 스승, 흑수회, 무너진 신념을 한 번에 전달 |
| Z3 | 백동수 처치 후 대사: "현무의 가갑은 증기를 가득 채운 칼만이 뚫는다. 그리고 가슴의 빛을 노려라." | 현무 공략(증기발도, 신핵)을 미리 알려준다 |
| Z4 | 장승에서 강화 1회 선택(체력 / 공격력 / 패링 증기량 중 1) | 강화 시스템을 한 번 체감 |

## 2. 시스템 — 루트에 맞춘 최소 세트

> 수치는 통합 기획서(10.07)의 **본문 채택 값**을 따른다. 충돌 항목은 이 문서에서 하나로 정했다(5장).

### 2-1. 조작

| 키 | 동작 |
|---|---|
| WASD / SHIFT | 이동 / 전력질주 (스태미나 없음) |
| SPACE | 구르기 (0.9초, 무적 0.5초) |
| 좌클릭 / 우클릭 | 환도: 약공격 / 강공격 · 화승총: 발사 / 조준(홀드) |
| TAB | 환도 ↔ 화승총 |
| C | 발도·납도 |
| **CTRL** | 패링(빨리뽑기) |
| **Z** | 증기발도 (증기 100일 때만) |
| **Q** | 시간 역행 |
| E | 회복약 |
| F | 상호작용 (장승, 대화) |
| T / 휠클릭 | 락온 (대상 전환 없음) |

### 2-2. 패링 = 빨리뽑기

| 항목 | 값 |
|---|---|
| 대상 | 패링 가능한 강공격만 (동심원 2개가 수축) |
| 입력 | CTRL, 좌측 허리 권총을 뽑아 쏨 |
| 판정 | 원이 겹치는 순간 ±0.15초(총 0.3초)부터 테스트. **시연 빌드는 ±0.2초** |
| 소모 | 증기 10 (입력 순간, 10 미만이면 불가) |
| 성공 | 공격 무효, 적 자세 붕괴, **약점 노출 3초**(다음 공격 1회 3배), 증기 +20 |
| 쿨타임 | 2초 |

### 2-3. 증기

| 행동 | 변화 |
|---|---|
| 약공격 적중 / 강공격 적중 | +5 / +10 |
| 패링 성공 | +20 (강화 시 +30) |
| 패링 시도 | −10 |
| 화승총 발사 | −10 |
| 시간 역행 | −70 |
| 증기발도 | −100 (전량) |

- 최대 100. 100이 되면 등의 증기통에서 **붉은 증기**가 나오고 환도가 달아오른다(= 개발팀 초안의 '과열' 시각 표현).
- 사망 후 재시작하면 0.

### 2-4. 증기발도 (= 고압 참격 = 과열 발도)

세 문서에 따로 있던 "과열 모드·고압 참격·증기발도(과열 발도)"를 **기술 하나로 합친다.**

| 항목 | 값 |
|---|---|
| 조건 | 증기 100 |
| 입력 | Z |
| 동작 | 준비 0.3초 → 전방 4.5m, 180° 베기 → 총 0.9초 |
| 피해 | 약공격 × 6 |
| 특수 | **현무의 흑철 가갑을 부수는 유일한 수단** |

- 과열 중 체력 지속 감소, 공격 속도 증가 같은 '모드'는 넣지 않는다. 판정·밸런스 작업을 줄이기 위해서다.
- **핵심 선택:** 증기 100을 모아 **증기발도로 쓸지**, 위험할 때 **70을 시간 역행에 쓸지** 고르는 순간이 이 게임의 긴장이다.

### 2-5. 시간 역행

| 항목 | 값 |
|---|---|
| 되감는 길이 | **5초** |
| 비용 | 증기 70 |
| 쿨타임 | 없음 (증기가 제한 역할) |
| 연출 중 | 무적, 조작 불가 (약 0.8초) |
| 되돌리는 것 | 위치, 방향, 체력, 발도 상태, 장착 무기 |
| **되돌리지 않는 것** | **증기 게이지**, 적과 보스, 장승·퀘스트 진행 |
| 연출 | 평소 발자취에 옅은 먹선 → 발동 시 먹선이 과거 위치로 빨려 들어감, 화면 청색 |

- 증기를 되돌리면 비용 70이 공짜가 되므로 **증기는 되돌리지 않는다.**
- 플레이어의 시간 역행은 적과 보스에게 영향을 주지 않는다. 백동수의 짧은 되감기, 현무의 시간 역류는 **보스 자신의 기술**이라 원칙과 충돌하지 않는다.

### 2-6. 플레이어 수치

| 항목 | 기본 | 강화 1회 시 |
|---|---|---|
| 체력 | 100 | 115 |
| 공격력(약공격) | 10 | 15 |
| 강공격 | 약공격 ×2 | — |
| 화승총 | 강공격과 같음 (히트스캔, 25m) | — |
| 회복약 | 2개, 최대 체력 50%, 장승에서 보충 | — |

- **배율 중첩 규칙:** 약점 노출 3배는 다음 공격 1회에만, 공격 종류와 상관없이 기본 피해에 곱한다. 원거리도 적용된다. 다른 배율과는 곱하지 않는다.

## 3. 적과 보스

### 3-1. 길 위의 적 (3종)

| 적 | 구역 | 체력 | 공격 | 패링 가능한 강공격 |
|---|---|---|---|---|
| 근접 잡몹 (변이 포졸) | Z1 | 50 | 창 찌르기 10 | **내려치기 15** |
| 원거리 잡몹 (흑수회 궁수) | Z1 | 40 | 화살 8, 2.5초 간격 | 없음 (접근하면 쉽게 처치) |
| 석탄 두더지 | Z2 | 100 | 할퀴기 10, 돌진 12 | **굴착 기습 18** (튀어나오기 직전 동심원) |

- 두더지 **석탄통에 화승총을 맞히면 한 방 처치**. 흙바닥에서만 땅굴 이동, 돌바닥에서는 지상으로 나온다.
- 적 AI는 팀의 `NGH_EnemyAI`(배회·인지·추적·근접)를 쓰고, 패링 훅(예고 표시, 자세 붕괴, 약점 노출)만 추가 요청한다.

### 3-2. 중간보스 — 백동수 (Z3)

**콘셉트:** 갑옷무사형(통합 기획서) + 서리 검객(개발팀 초안) 병합. "패링을 써야 이기는 보스"이자 패링 졸업 시험.

| 항목 | 값 |
|---|---|
| 체력 | 300 |
| 방어 | 서리 갑옷: 평소 받는 피해 ×0.3. **약점 노출 중에는 ×1.0** (그래서 패링 후 3배가 사실상 10배 차이) |
| 그냥 때려서 잡기 | 가능하지만 약 100타 → 사실상 패링 강제 |

| 패턴 | 예고 | 피해 | 패링 |
|---|---|---|---|
| 초고속 발도 | 칼집에 손 + 동심원 0.6초 | 20 | **가능** |
| 삼연 베기 | 칼이 백색으로 빛남 | 10 × 3 | 마지막 3타만 가능 |
| 서리 검기 | 바닥에 백색 선 0.7초 | 15 | 불가 (구르기) |
| 짧은 되감기 (체력 50% 이하) | 백동수 주변에 백색 먹선 | — | 패링 당한 직후 1회, 자신을 2초 전 위치로 되돌림(체력 회복 없음) |

- **처치 보상:** 특별한 석탄 1 → 장승 ②에서 강화 1회. 현무 공략 대사.

### 3-3. 최종보스 — 현무 (Z5, NMJ 보스 아레나)

**공통:** 연못 중앙, 초당 30° 회전으로 플레이어를 바라본다. 몸통 콜라이더로 안쪽 진입 차단.

#### 1페이즈 [흑철의 가갑] — 가갑 4장 파괴

| 패턴 | 예고 | 피해 | 대응 |
|---|---|---|---|
| 흑철 찍기 | 발 위로 **동심원** 1.0초 | 25 | **패링 가능** → 현무 자세 붕괴 1.5초 + 증기 +20 |
| 꼬리 휩쓸기 | 몸 둘레 적색 고리 1.3초 | 20 | 구르기 |
| 시간 역류 (가갑 2장 이하일 때 1회) | 청색 고리, 4초 시전 | — | 머리를 4번 치거나 증기발도로 끊기. 못 끊으면 가갑 1장 복원 |

- 가갑은 일반 공격으로는 증기만 오르고 부서지지 않는다. **증기발도(Z)로만 파괴**.
- 루프: 찍기 패링 → 증기 → 100 → 증기발도 → 가갑 1장.

#### 2페이즈 [쌍두의 폭주] — 체력 600

| 패턴 | 예고 | 피해 | 대응 |
|---|---|---|---|
| 뱀의 목 찌르기 | 백색 잔상이 목표 지점에 먼저 내려앉음 + 동심원 | 22 | **패링 가능** → 뱀 머리 2.5초 박힘 |
| 냉기 브레스 | 청색 부채꼴(55°, 16m) 1.3초 | 0.25초마다 5 | 구르기 |
| **합동기** (체력 50%에서 1회) | 4초 충전, "피할 수 없다 — Q" | 체력 90% (1 미만으로 안 떨어짐) | **시간 역행으로 충전 전 위치로 돌아가 피한다**. 증기 70을 남겨 두는 판단을 요구 |

- 합동기 직전 4초 동안 증기가 70 미만이면 바닥에 증기 구슬 3개를 떨어뜨려 채울 수 있게 한다(시연 막힘 방지).

#### 마무리 — 신핵 QTE → 해빙 엔딩

체력 0 → 현무가 주저앉고 가슴의 **신핵(황)** 노출 → F → [Z] → [좌클릭] → [Q] 3단 입력(단계당 2초) → 혼천의가 신핵에 박혀 역회전 → 해빙.

## 4. 맵 제작 명세

### 4-1. 씬 구성

## 7. 완료 체크리스트

1. 시작부터 엔딩까지 씬 전환 2번으로 끊김 없이 이어진다.
2. 플레이어가 Z1에서 패링을, Z2에서 시간 역행을 **반드시 한 번** 경험한다.
3. 백동수를 패링 없이 잡으려 하면 확실히 손해다(약 100타).
4. 현무 가갑은 증기발도로만 부서진다.
5. 합동기를 시간 역행으로 넘길 수 있고, 증기가 모자라면 구슬로 보충된다.
6. 처음 해 보는 사람이 10분 ± 2분 안에 엔딩을 본다.
7. 사망하면 최근 장승에서 체력 가득, 증기 0으로 다시 시작한다.
